# Reports and activity logs

`ReportsPage.tsx` uses `reportsApi` for SKU and customer views. The Sales Funnel counts the same product inquiries, with the same stage rules, as the Inquiries filter. The Total Tonnage card uses the same won-order list as the dashboard and Orders page (`ordersApi.getAll`), not the smaller overview order set. SKU Breakdown, Login activity, and Customer Visits each show 15 rows per page. Its customer-visit table shows Verification, Location, Photo, and Documents. Verification is Phone verified or Phone not verified when `phone_verified` is set. Location shows the city and whether it was a GPS location or a typed location. Sync Bigin is shown there only for a signed-in admin or salesperson, then the overview is refetched. Admins also see a Login activity table from `activityLogsApi` (`module: Auth`) for the current rep and date range. `LogsPage.tsx` queries `activityLogsApi` with module, date, search, salesperson, mode, and limit filters. Admins get a Login / Logout module (salesperson filter, IST times, duration, and CSV) and a User Management module (activate, deactivate, delete), each with an action filter. Salesperson views do not include those rows.

Reports are server-derived and scope-sensitive. Activity logs are business audit records—not a client telemetry sink. Validate filter state and pagination when changing either page.
