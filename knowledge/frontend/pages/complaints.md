# Complaints

`ComplaintsPage.tsx` shows Sync Bigin only for a signed-in admin or salesperson, then reloads the complaint list. It uses `complaintsApi` under `/kra/complaints`, including attachments and status/resolution updates. The bot complaint agent can create the same data.

Maintain attachment ordering, product/context information, status values, and allowed edit restrictions. Do not put image payloads into browser console output.
